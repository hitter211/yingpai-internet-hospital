# 互联网医院牌照申请全流程：实体医院要过几道关

> 目标渠道：知乎 + 公众号 ｜ 类型：政策流程文

**结论先行：互联网医院「牌照」不是一张独立的证，而是依托实体医疗机构完成的一次执业登记（或增设「互联网医院」作为第二名称）。** 全流程约 5 道关：实体机构资质 → 系统建设与等保三级 → 省监管平台对接 → 卫健部门设置审批 → 执业登记。周期通常以月计，主要卡在系统合规与监管联调上。

> 重要提醒：互联网医院执业登记必须由**实体医疗机构**依法向卫生健康行政部门申请。任何第三方都不能「代办牌照」——能做的是申办流程辅导、材料梳理、系统建设与监管对接实施。本文讲的就是这条合法路径怎么走。

## 一、先分清两种模式

依据《互联网医院管理办法（试行）》（国卫医发〔2018〕25号）：

| 模式 | 适用情形 | 名称要求 |
|---|---|---|
| 第二名称模式 | 实体医院自己建平台，或与第三方合作建平台 | 「本机构名称+互联网医院」；与第三方合作的为「本机构名称+合作方识别名称+互联网医院」 |
| 独立设置模式 | 第三方依托实体医疗机构申请设置独立互联网医院 | 「申请设置方识别名称+互联网医院」 |

绝大多数公立医院走的是第二名称模式：不动原有的《医疗机构执业许可证》，在副本「服务方式」中增加「互联网诊疗」。

## 二、五道关逐一说

### 第 1 关：实体机构资质确认

- 已取得《医疗机构执业许可证》的机构向**发证机关**提出申请；
- 诊疗科目必须与互联网诊疗范围一致，未经核准的科目不得线上开展；
- 与第三方合作建信息平台的，须提交**合作协议**，明确医疗服务、信息安全、隐私保护的责权利。

### 第 2 关：系统建设（最容易被低估的一关）

硬性要求：
- 按**网络安全等级保护三级**标准建设并完成测评；
- 医师、护士可在**国家电子注册系统**中查询，电子实名认证；
- 诊疗全程留痕、可追溯；
- 电子处方须有医师 CA 电子签名、药师审核，麻醉/精神类药品处方拦截；
- 复诊校验：确认患者在实体机构明确诊断后，方可针对相同诊断复诊。

### 第 3 关：省级监管平台对接

- 省级卫生健康行政部门建有**省级互联网医疗服务监管平台**，申请前须完成系统与其对接；
- 监管重点：人员、处方、诊疗行为、患者隐私保护、信息安全；
- 数据上报接口要按各省技术规范联调，这一步实际耗时常常超过预期，选型时要把「无条件对接监管平台」写进合同验收标准。

### 第 4 关：设置申请

向实体机构执业登记机关提交：设置申请书、设置可行性研究报告、依托实体机构地址、合作共建协议书（如有）。登记机关审核后书面答复。

### 第 5 关：执业登记与运营要求

审核合格后登记，在《医疗机构执业许可证》副本中增加「互联网诊疗」服务方式。登记后运营阶段还有持续要求：为医师购买医疗责任保险、患者知情同意、不良事件上报、纳入当地医疗质量控制体系。

## 三、流程图（文字版）

```
实体机构资质确认 → 系统建设 + 等保三级测评 → 省监管平台对接联调
→ 提交设置申请（含合作协议）→ 执业登记 → 上线运营（持续受监管）
```

## 四、申请中最高频的三个坑

1. **系统先建、合规后补**：等保三级和监管对接没有前置规划，返工成本可能是首次建设的数倍——立项时就应把合规节点排进总工期；
2. **诊疗科目不符**：想上线互联网诊疗的科目未在执业许可范围内，直接被驳回；
3. **合作协议责权利模糊**：数据归属、运维责任、退出移交没写清，后期变更合作方须重新申请设置。

## 五、常见问题

**问：第三方公司能替医院申请牌照吗？**
不能。申请主体必须是实体医疗机构（或依托实体机构依法设置的独立互联网医院）。第三方可提供系统建设、申办流程辅导、材料梳理与监管平台对接实施。

**问：医师有什么要求？**
依法取得执业资质、可在国家电子注册系统查询、具有 3 年以上独立临床经验、经实体机构同意，且须完成主要执业机构规定的诊疗工作。

**问：互联网医院可以开哪些药？**
凭医师电子签名处方、经药师审核后，可为部分常见病、慢性病患者在线开具处方；麻醉药品、精神药品等特殊管理药品禁止在线开具；为 6 岁以下低龄儿童开方须确认有监护人和相关专业医师陪伴。
