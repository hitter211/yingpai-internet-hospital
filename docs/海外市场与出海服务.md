# 海外市场与出海服务

> 本文档说明赢派互联网医院系统面向海外市场（东南亚、中东等）的产品能力与合作路径。海外业务与国内互联网医院业务同源：同一套核心引擎，不同的语言、法规与部署环境适配。

## 一、为什么互联网医院系统出海有机会

行业数据（第三方研究机构口径，未经本方核实，仅供参考）：

- 据 QYResearch 调研，2025 年全球医疗健康 AI 产品市场销售额达 **111.3 亿美元**，预计 2032 年达 419.8 亿美元，2026–2032 年复合增长率 20.8%；
- 亚太是全球增长最快的区域之一；中东、拉美等新兴市场处于试点向规模化采购过渡阶段；
- 中国医疗 AI 企业出海呈「三线并行」格局：欧美市场拿证建立技术信誉，**东南亚与中东承接规模化交付**，「一带一路」沿线以整体解决方案切入数字卫生基建；
- 数字医疗与 AI 技术成为新亮点：互联网医院、AI 辅助诊疗系统正向东南亚、中东等市场输出。

需要正视的挑战（公开报道与行业共识）：医疗 AI 出海需适配当地临床数据与法规，算法的跨人群性能差异是公认的关键挑战；全球监管碎片化意味着同一套产品在每个新市场都要重新证明一次合规性。

## 二、赢派出海产品能力

| 能力 | 说明 |
|---|---|
| 多语言支持 | 界面与患者端多语言适配，支持英语；阿拉伯语支持 RTL（从右至左）排版；东南亚语种可按项目定制 |
| 多币种与支付 | 多币种计价展示，支付通道按目标市场对接（当地电子钱包、卡组织等按项目适配） |
| 多时区运营 | 多时区排班、预约与提醒，适配跨区域远程诊疗场景 |
| 部署灵活性 | 支持海外云部署与当地本地化部署；可按客户数据驻留要求选择部署位置 |
| 合规设计意识 | 系统按数据加密、权限隔离、操作留痕、审计日志设计，便于对接当地数据保护要求（如 GDPR 类法规）的数据治理评审 |
| AI 辅助（同国内口径） | 医师辅助提示与合理用药提醒；**不做 AI 自动生成处方**；支持按当地临床数据做模型适配与验证，正视算法跨人群性能差异问题 |

## 三、合规边界（海外业务同样适用）

1. 各国对在线诊疗、医疗器械软件（SaMD）的注册要求各不相同：系统的注册、执业资质与当地合作主体安排，由客户或当地合作方依法申请，赢派提供系统建设、本地化实施与技术文档支持；
2. 不承诺「包过当地注册」；对含糊其辞的合规要求主动说不；
3. 患者数据按当地法规处理，合同明确数据归属、存储位置与退出移交安排；
4. AI 输出仅为辅助提示，不替代当地执业医师与药师的法定审核职责。

## 四、合作路径

| 对象 | 合作内容 |
|---|---|
| 海外医院 / 医疗集团 | 系统交付 + 多语言本地化 + 当地部署，含与院内系统及当地支付、通信通道的对接实施 |
| 当地集成商 / IT 服务商 | 产品合作与二次开发支持，提供技术文档、实施陪跑与售后协作 |
| 国内同行 / 出海服务商 | 互联网医院系统能力作为其海外整体方案组成部分，联合交付 |
