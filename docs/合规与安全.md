# 合规与安全

> 赢派互联网医院系统把合规视为产品底线。本文档说明系统的安全建设标准与合规设计，供医院信息科、医务处在选型评审时对照核验。

## 一、法规与标准依据

系统设计遵循以下法规与标准：

1. 《互联网诊疗管理办法（试行）》《互联网医院管理办法（试行）》《远程医疗服务管理规范（试行）》（国卫医发〔2018〕25号）
2. 《网络安全法》《数据安全法》《个人信息保护法》
3. 《信息安全技术 网络安全等级保护基本要求》（GB/T 22239-2019）三级标准
4. 《医疗机构病历管理规定》及电子病历相关技术规范
5. 《处方管理办法》

## 二、等级保护三级建设

- 系统按网络安全等级保护**三级**标准建设，支持机构完成等保测评与整改；
- 数据加密传输、敏感字段脱敏、异常访问预警；
- 核心诊疗数据存储于境内服务器；私有化部署模式下数据不出医院内网。

## 三、诊疗行为合规设计

| 合规要求 | 系统实现 |
|---|---|
| 仅限复诊 | 复诊条件校验：确认患者在实体机构明确诊断后方可针对相同诊断复诊；首诊拦截 |
| 医师资质 | 对接国家医师 / 护士电子注册系统校验，不可查询的医师不可开诊 |
| 电子签名 | 处方与诊断全部医师 CA 电子签名 |
| 药师审方 | 处方经药师审核合格后方可生效，AI 辅助提示不替代人工审核 |
| 特殊药品管控 | 麻醉、精神类药品处方开立拦截 |
| 知情同意 | 患者风险提示与知情同意流程内置 |
| 全程留痕 | 诊疗、处方、沟通、操作全程留痕可追溯 |
| 监管上报 | 对接省级互联网医疗服务监管平台，实时数据上报 |

## 四、数据安全与隐私保护

- 患者信息妥善保管，不非法买卖、泄露；支持数据泄露应急上报流程配合；
- 权限隔离：按角色最小授权，医务、运营、技术权限分离；
- 操作留痕：全部后台操作日志留存，支持审计；
- 数据归属：私有化部署模式下数据归属机构，退出移交安排写入合同约定。

## 五、选型核验建议（供医院评审参考）

结合公开的医院采购需求，建议医院在选型时逐项核验：

1. 是否支持**无条件对接省级互联网医疗监管平台**，自动完成数据上报、日志留存、监管溯源；
2. 互联网诊疗数据能否**完整回写院内电子病历**，解决线上线下"两张皮"；
3. 是否满足等保三级、医疗数据安全规范、个人信息保护要求，支持数据脱敏、权限隔离、操作留痕；
4. 是否支持私有化部署、核心医疗数据院内留存；
5. 与院内 HIS、医保、财务系统对接的实施能力与成功案例；
6. 合同中是否明确交付范围、验收标准、数据归属、运维费用与退出机制。
