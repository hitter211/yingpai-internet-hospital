# 功能清单与模块说明

> 本文档为赢派互联网医院系统功能模块的详细说明，依据《互联网诊疗管理办法（试行）》《互联网医院管理办法（试行）》及公开医院采购需求要点整理。

## 1. 在线诊疗服务

| 功能 | 说明 |
|---|---|
| 在线复诊 | 图文 / 语音 / 视频三种问诊形式；仅面向在实体机构明确诊断后的常见病、慢性病复诊，系统内置复诊条件校验 |
| 预约挂号 | 号源池管理、排班规则、患者自助预约与改约 |
| 健康咨询 | 非诊疗类咨询服务通道，与诊疗流程隔离 |
| 病情变化引导 | 患者出现病情变化需线下诊查时，系统支持终止线上诊疗并引导至实体机构的流程留痕 |

## 2. 电子处方与流转

| 功能 | 说明 |
|---|---|
| 在线开方 | 医师掌握患者病历资料后针对相同诊断开具处方 |
| CA 电子签名 | 对接第三方 CA 机构，所有在线诊断、处方均有医师电子签名 |
| 药师审方 | 独立药师审核工作流，审核合格后处方方可生效 |
| 处方流转 | 按患者自主选择流转至医疗机构或药品经营企业，支持委托符合条件的第三方配送 |
| 风险管控 | 麻醉药品、精神药品等特殊管理药品处方开立拦截；6 岁以下低龄儿童处方监护人确认流程 |

## 3. 监管对接与留痕

| 功能 | 说明 |
|---|---|
| 省监管平台对接 | 按各省技术规范完成数据上报接口对接与联调测试 |
| 全程留痕 | 诊疗行为、处方、聊天记录、操作日志全程留痕、可追溯 |
| 监管溯源 | 向监管部门开放数据接口，支持数据上报、日志留存、监管溯源 |
| 电子病历管理 | 按《医疗机构病历管理规定》与电子病历相关规范建立和管理患者电子病历，支持患者在线查询检查检验结果、诊断治疗方案、处方医嘱 |

## 4. 院内系统集成

| 功能 | 说明 |
|---|---|
| HIS 对接 | 挂号、收费、医嘱业务联动 |
| LIS / PACS 对接 | 检查检验申请与结果回传 |
| 电子病历回写 | 互联网诊疗数据完整回写院内电子病历系统，解决线上线下业务"两张皮" |
| 医保接口 | 按地区政策适配互联网复诊医保结算接口 |

## 5. 医务与人员管理

| 功能 | 说明 |
|---|---|
| 医师资质校验 | 对接国家医师 / 护士电子注册系统查询校验，仅允许可查询医师开展互联网诊疗 |
| 电子实名认证 | 医务人员电子实名认证，支持人脸识别加强管理（可选） |
| 3 年经验管理 | 医师独立临床工作年限信息登记与开诊校验 |
| 排班号源 | 多院区、多科室排班与号源统一管理 |

## 6. AI 辅助（合规定位）

| 功能 | 说明 |
|---|---|
| 医师辅助提示 | 辅助诊断提示信息，仅作医师决策参考 |
| 合理用药提醒 | 用药禁忌、相互作用、剂量提示 |
| 合规边界 | **不支持且不提供 AI 自动生成处方**。AI 输出仅为辅助提示，处方由本院医师开具、药师审核 |

## 7. 患者服务与运营

| 功能 | 说明 |
|---|---|
| 报告查询 | 检查检验报告在线查询 |
| 随访管理 | 术后 / 慢病随访计划与任务 |
| 数据看板 | 接诊量、处方量、科室工作量统计 |
| 不良事件 | 医疗服务不良事件与药品不良事件上报流程支持 |

---

以上功能清单以实际交付合同约定为准。欢迎通过仓库 Issues 提问或站内私信获取演示。
