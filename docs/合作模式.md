# 合作模式

> 本文档说明赢派互联网医院系统的两类合作路径。具体商务条款以双方正式合同为准。

## 一、面向医院机构

### 交付路径

| 模式 | 说明 |
|---|---|
| SaaS 云端 | 账号开通即用，标准化问诊 / 复诊 / 处方流程，上线周期短，适合快速试水的专科机构 |
| 私有化部署 | 系统部署于院内，核心医疗数据不出内网，支持与 HIS / LIS / PACS / 医保 / 财务系统深度对接 |
| 混合模式 | SaaS 快速上线 + 关键模块定制与敏感数据隔离 |

### 我们提供

1. 选型咨询与方案设计：结合医院功能定位、诊疗科目、预算与信息化现状；
2. 系统建设与院内集成：含接口开发、数据调试、系统改造配套；
3. 省级监管平台对接联调与等保测评配合；
4. 上线试运行、人员培训与持续运维；
5. 政策合规跟踪：互联网诊疗监管政策更新同步与系统适配。

### 边界说明（我们主动不做什么）

- 不承诺、不代办互联网医院执业登记——该项须由依托的实体医疗机构依法向卫生健康行政部门申请，我们提供申办流程梳理、材料准备辅导与监管对接实施；
- 不以 AI 自动审方替代执业药师人工审核，不提供 AI 自动生成处方能力；
- 不承接违反等保要求与监管要求的系统方案；
- 合作回报不与诊疗收入、药品销售收入、医保结算金额及处方流转量挂钩。

## 二、面向渠道商与集成商

### 合作内容

- 产品合作：赢派互联网医院系统面向区域 HIS 集成商、医疗信息化同行提供合作交付；
- 二次开发支持：开放接口文档与技术支持，支持渠道商基于客户需求做本地化适配；
- 项目陪跑：投标技术方案支持、监管对接实施支持、上线与运维支持。
